Independent model repository owned by __OWNER__, generated by AI Platform.
Commit model code, tests, params.yaml, dvc.yaml, dvc.lock, metrics and DVC
pointers here. Keep datasets and model binaries in your approved DVC remote.

1. Create a venv and install requirements-dev.txt.
2. Implement load_training_data and build_and_evaluate in src/train.py.
   The starter intentionally requires your model and data contract.
3. Put input at data/training.csv (or update dvc.yaml). Track external input

4. Configure an approved remote: `dvc remote add -d datasets s3://BUCKET/PREFIX`.
   Store endpoint configuration in `.dvc/config.local` using `--local`,
   and credentials in environment variables or your identity provider.
5. Run `dvc repro`, review metrics, run tests, then `dvc push`.
6. Commit code, DVC metadata and metrics in this repository. Publish with
   `gh repo create OWNER/REPO --private --source . --push` after first commit.
7. Set MODEL_NAME, DATASET_VERSION, SOURCE_GIT_SHA and MLFLOW_TRACKING_URI;
   run src/train.py to register a numeric MLflow version.
8. Submit only model-template.json as a catalog entry in a separate platform
   PR. After rollout, request deployment and obtain separate approval.

CI runs contract tests. Enable authenticated DVC pull/repro checks after
implementing the project and configuring your approved data access.
